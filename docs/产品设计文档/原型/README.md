# 贯通原型操作说明

## 评审工具

顶部控制条不属于产品。平台决定能力展示，角色切换用于快速比较；首次设置按钮重置到仅本机示例，恢复按钮回到六台电脑。故障选项用于展示只读、写失败、无权限、无发现、身份变化等分支。

异步结果从“引擎／对端事件”选择后点“发出示例事件”：来源等待时发出另一台电脑请求；本机核对后发出对方确认；连接中发出成功／失败；验证步骤发出跨屏输入；应用中发出应用成功／失败。按钮操作不会自动假定外部步骤成功。

## 三条推荐路径

1. 首次提供键鼠 → 权限 → 等待 → 评审请求事件 → 核对完整指纹并勾选 → 等待对方确认事件 → 连接事件 → 位置 → 输入事件或稍后 → 设备页。
2. 恢复六台 → 切接收端 → 更换来源 → 选择／手动 → 核对 → 模拟拒绝或失败 → 取消 → 检查旧来源仍连接；再次尝试成功后才切换。
3. 恢复六台 → 设置共享、网络或配置文件 → 保存 → 应用确认 → 模拟失败再重试成功 → 检查生效版本与待连接 → 发出连接事件 → 菜单、诊断查看同一状态。

额外检查：信任撤销／重新核对不自动连接；布局取消；多动作快捷键；证书无效／重建；日志搜索／预览；Windows服务停止失败；无后台入口关闭；后台掉线通知和重复去重。

## 产品页面入口

侧栏提供设备、设置、诊断、帮助。设置选项卡进入通用、共享、快捷键、接收输入、网络、信任与高级；高级子页相互可达。设备图块／列表进入高级设置。诊断可进技术日志；标题栏“菜单栏／托盘”打开系统面板示意。顶部“定位页面”仅便于评审直达。

## 测试

安装Node.js与Python3；在本设计目录运行 `npm install`、`npx playwright install chromium`、`npm test`；文档检查用 `npm run check:docs`。也可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向已有兼容Chrome，无需下载浏览器。测试将启动临时无头浏览器，不启动产品。可设置 `DESIGN_SCREENSHOT_DIR` 为已存在目录输出评审截图。

锁定开发依赖 Playwright 1.62.1；只用于设计验收，不进入产品构建。图标为本地 Lucide 资源，附独立许可。实现边界及原型简化见 [整体确认清单](../10_整体确认清单与决策记录.md)。
