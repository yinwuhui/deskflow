## 首次提供键鼠

S01 选择键鼠在本机 → 检测本机所需授权 → 进入等待页，显示实际本机标识与可用地址 → 在另一台电脑选择接收输入并发起连接 → 本机收到请求后核对完整指纹 → 本地明确确认 → 等待对方核对本机 → 引擎尝试建立安全连接 → 收到连接成功事件 → 安排位置 → 引导实际跨屏输入 → 显示已验证或稍后验证 → S02。

来源端不以 mDNS 搜索接收端作为默认流程。没有请求时可预先添加离线电脑，但该图块仅表示配置，不代表已信任或已连接。首次授权失败必须保留可恢复的界面；现有入口提前退出的行为需要接入调整。

## 首次接收输入

选择键鼠在另一台电脑 → 权限检测 → 浏览来源服务 → 选择来源或手动填写地址／端口 → 双方身份核对 → 等待连接结果 → 显示本机与来源 → 跨屏验证。无发现时给网络／防火墙说明、刷新和手动地址入口；多个地址按当前核心解析语义及优先级处理，失败时展示实际尝试的地址与原因。

接收端不能编辑来源端完整排列；没有拓扑同步时不绘制虚构的多设备布局。接收端自己的重试、语言和滚轮仍可编辑。

## 日常添加与更换来源

- 添加：S02“添加电脑”进入同一个助手；既有连接、布局和草稿继续保留；取消只结束本次尝试。
- 更换来源：记录旧来源为 active、新来源为 candidate；新来源完成必要身份确认并可用后才提交切换。拒绝、超时、取消、授权失败均回到旧来源状态。
- 重验身份：S09 → 特定设备身份页 → 本机和必要的对端确认；结束后仍保持原离线状态，用户另行连接。不能把信任成功作为输入成功。
- 重新验证输入：S13 或未验证设备详情进入该设备验证步骤。断线历史可显示“曾验证”，当前会话就绪仍看连接与权限。

## 修改与应用

打开设置 → 修改形成页面草稿 → 离开可保留草稿，返回恢复 → 保存成功后显示“已保存，待应用”和范围 → 确认影响 → 应用中 → 失败保留可编辑版本和原生效版本，说明运行是否仍在；成功更新生效版本 → 等待真实重连 → 独立显示输入验证。

排列有自己的编辑会话。离开未保存排列时提供返回／放弃；设备、规则弹窗关闭时处理未保存修改。普通显示偏好自动保存，系统能力实际注册结果另示。

## 后台故障与退出

前台故障显示持久横幅与就近错误；后台有权限时发一次重要通知并保留托盘标记。点击通知打开对应设备／诊断／信任页；未授权通知仍可继续共享。

关闭主窗口按偏好隐藏到可用后台入口或明确退出；后台入口不可用时保持可返回窗口。macOS Cmd+Q 与系统退出是明确退出。Windows 服务模式提供“停止共享并退出”和“仅退出界面（共享继续）”；停止失败保持界面，不能显示已停止。系统关机／注销走受支持的清理路径，不用交互弹窗阻止操作系统结束。

## 恢复入口

应用失败留在待应用区；发现失败保留手动入口；身份变更留在 S09；权限失败跳到系统指引并返回检测；文件不可读允许恢复上一个生效配置；日志写入失败允许换路径而不影响会话；服务失败允许回到受支持桌面模式。恢复过程均不自动降低 TLS、不清空信任、不执行本机命令。
