# 08 验收标准与测试计划

版本 v1.0 开发基线；授权与实现证据见 [决策记录](10_整体确认清单与决策记录.md)。设计原型检查和未来产品验收是两类证据。当前实测结果见 [验证结果](测试/验证结果.md)，下表是开发交付必须满足的验收要求，不代表已经通过。

## 可追踪的验收场景

| 编号 | 需求 | Given / 前置 | When / 操作 | Then / 期望 |
|---|---|---|---|---|
| AT-01 | REQ-01 | 同一运行会话 | 切设备、诊断、菜单 | 角色、连接数与问题一致；导航不切角色 |
| AT-02 | REQ-02 | 首次提供键鼠 | 完成授权，在接收端发起 | 来源等待请求，双方核对后才连接，连接后仍待输入验证 |
| AT-03 | REQ-02 | 首次接收，无发现／无权限 | 拒绝授权、使用手动地址、返回 | 可恢复且保留输入；不提前退出或假成功 |
| AT-04 | REQ-03 | 旧来源已连接 | 新来源拒绝、超时、失败或取消 | 切换允许短暂中断；失败／取消后恢复旧来源；恢复成功与失败分别报告，已保存候选配置与布局保留 |
| AT-05 | REQ-04 | 多行多列、空位、离线布局 | 交换、缩放、坐标、取消、保存 | 全部设备保留；取消还原；断路可明确保留；不超过模型范围 |
| AT-06 | REQ-05 | 多别名和映射设备 | 重名、重命名、四角／修复保存 | 全局唯一校验、引用一致，六类映射与None完整保留 |
| AT-07 | REQ-06 | 已有规则 | 重复组合、释放动作、多目标、重排、重启 | 明确冲突；顺序和事件类型无损；重启有确认且保存不执行 |
| AT-08 | REQ-07 | 共享与接收端预设 | 边界值、双触+延迟、两轴倍率 | 范围正确、独立开关共存，接收端本地可改且不反转旧语义 |
| AT-09 | REQ-08 | 有草稿和旧生效版本 | 写失败、应用失败、应用中再保存 | 草稿不丢；版本准确；迟到结果不清新待应用；连接需实际事件 |
| AT-10 | REQ-08 | 图形生效，文件模式已保存 | 应用成功／失败、退出文件模式 | 成功后才只读；失败仍旧配置；不覆盖外部文件 |
| AT-11 | REQ-09 | 已信任、已连接设备 | 身份变化、撤销、重新核对 | 变化阻断；撤销仅指定对象；再信任不自动连接 |
| AT-12 | REQ-09 | 正在共享，本机身份有效 | 重建失败／成功、换同路径不同身份 | 失败留旧身份；成功激活后停共享，所有远端需重验本机 |
| AT-13 | REQ-10 | 复杂旧配置／证书／外部路径 | 读取、编辑一字段、导出读回 | 语义无损，未知字段有保留策略；安全降级明确确认 |
| AT-14 | REQ-11 | 权限／身份／网络／输入异常 | 诊断、搜索日志、脱敏导出 | 下一步准确；六级日志保留；报告排敏感数据，无自动上传 |
| AT-15 | REQ-12 | 前台／后台同一故障 | 连续重试、恢复再掉线 | 同episode通知一次，恢复后新故障可提醒，前台横幅持续 |
| AT-16 | REQ-12 | 服务运行／无托盘／Mac窗口 | 关闭、CmdQ、停止失败、仅退界面 | 返回路径可用，明确退出不隐藏，服务停止失败不假报停止 |
| AT-17 | REQ-13 | 普通偏好及内外部文件 | 恢复偏好／清除配置／取消 | 范围不同、路径明确、导出可选；外部文件／服务不隐式删除 |
| AT-18 | REQ-14 | 四平台及便携／不同桌面 | 权限撤销、唤醒、切能力 | 保留暂停；能力驱动UI；X11修复不扩到Wayland |
| AT-19 | REQ-15 | 长文本、多语言、深浅色、200% | 全键盘、读屏、窄屏、弹窗 | 无关键截断；焦点正确；无仅拖拽／仅颜色操作 |
| AT-20 | REQ-16 | 全106控件及动态清单 | 功能迁移核对与实际配置回归 | 每项有实现和证据，不能用设计映射作为产品验收 |

[需求与验收映射 CSV](附录/需求与验收映射.csv) 可导入团队追踪工具；各测试还需在实现时附 owner、构建、平台、步骤、结果和缺陷链接。

## 测试层次

1. 模型单元／集成：状态不变量、attemptId／revision 竞态、变更引用、真实解析／序列化 roundtrip、失败注入、脱敏白名单。
2. Qt 页面测试：草稿、校验、禁用原因、焦点、键盘与用户动作；不为每个静态标签写镜像测试。
3. 核心／平台集成：真实两机输入、权限变化、服务停止结果、TLS／指纹替换、重新连接和生命周期。
4. 视觉与可访问：系统缩放、文本、主题、系统控件、屏幕阅读器；保留截图与环境记录。
5. 迁移：真实旧配置样本和未知字段，对照旧行为，验证升级／回退和可恢复备份。

## 平台验收矩阵

| 组合 | 至少覆盖 |
|---|---|
| macOS 来源 ↔ macOS 接收 | AX初次／拒绝／撤销、菜单栏、CmdQ、睡眠、键盘布局 |
| macOS ↔ Windows 桌面 | 双向角色、提权窗口、剪贴板、倍率、修饰键 |
| Windows 服务 ↔ 其他平台 | 安装／非便携、服务离线、停止失败、仅退出界面 |
| Windows 便携版 | 服务控件不误开放、配置路径、无安装依赖 |
| X11 ↔ macOS / Windows | 目标X11修复、焦点、桌面托盘差异 |
| Wayland ↔ 其他平台 | 实际支持组合器、Portal版本、拒绝／撤销、无托盘、能力未知 |

测试记录操作系统、Deskflow构建、Qt版本、后端、安装形态、角色、网络和能力结果。仅在HTML切换平台选择项不能证明这些组合可用。

## 发布门槛

所有 P0 与106映射有实现及证据；无配置／身份丢失、误信任、假停止等阻断缺陷；旧格式 roundtrip 通过；核心平台有实机输入证据；所有新能力合同已实现或经整体确认降级。文档、原型与产品不一致需记录已确认的变更。开发已获授权，发布仍须完成此处实机验收，不以开发授权或历史原型检查代替。
