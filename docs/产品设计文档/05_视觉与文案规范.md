# 05 视觉与文案规范

版本 v0.9 · 待整体确认。原型提供统一的实色分层；实现采用 Qt 的平台字体、控件语义与系统外观。以清晰和稳定为先，不要求为视觉效果重写渲染栈。

|---|---|---|---|
| surface.window | #F7F8FA | #21252B | 主工作区 |
| surface.panel | #FFFFFF | #2B3038 | 表单、弹窗、菜单 |
| surface.sidebar | #EEF0F4 | #282D34 | 导航层 |
| text.primary | #27303B | #EDF1F8 | 标题与正文 |
| text.secondary | #626E7F | #AEB8C7 | 说明，不承载唯一关键信息 |
| border.default | #DCE2EA | #454F5E | 层级与输入框 |
| action.primary / onPrimary | #0867D5 / #FFFFFF | #85B8FF / #16253A | 一个区域一个主要动作 |
| status.success | #26764C | #8ED4AA | 附“已连接／已验证”等文本 |
| status.warning / background | #88550D / #FFF4DF | #ECC17D / #433724 | 待处理与兼容说明 |
| status.error | #B93C36 | #F0AAA3 | 错误、撤销、删除 |

这些是原型基准色；Qt 高对比模式优先系统调色板，并重新测试控件文字、选中、禁用和焦点对比。颜色对比须达到 WCAG AA：普通正文4.5:1，较大文字和必要图形3:1；不能仅凭色值表宣称已通过全部系统环境。

| 维度 | 建议规格 |
|---|---|
| 字体 | macOS 系统字体、Windows Segoe UI、Linux 桌面默认无衬线；等宽用于指纹与日志 |
| 正文 / 说明 / 页标题 | 14 / 12 / 23 逻辑像素基准；随系统字号与 DPI 缩放 |
| 字重 | 正文400、标题／选中600；不靠超细字表达状态 |
| 间距 | 4、8、12、16、24、32；页面边距24–26，分组间距20–24 |
| 控件 | 紧凑桌面按钮最小视觉高30–32；常用目标建议至少32×32，触控环境放大 |
| 圆角 | 控件6，面板8，窗口／菜单10–13；原生窗口边框由平台决定 |
| 图标 | 统一线性图标16–20，附标签；原型 Lucide 已附许可；产品可用现有 Qt 图标系统 |
| 窗口 | 默认建议1100×780逻辑像素，最小建议800×600；不是最终已测产品限制 |
| 小尺寸 | 原型320宽提供评审回退；桌面小屏／200%缩放使用滚动与位置列表，不把全部区域硬挤 |

## 组件与状态

- 主导航固定文字和图标；选中项有底色及语义选中状态。设置选项卡只做页内分类，高级页有明确返回／相邻入口。
- 主按钮用于下一步、保存、应用；次按钮用于取消与检查；危险按钮用具体动词。禁用原因在邻近说明或辅助提示中可获得。
- 输入项有可访问标签、单位、合法范围和就近错误。开关关闭时禁用依赖输入但保留数值，不在用户重新启用后丢失设置。
- 连接、信任、输入验证分别用文字与小状态标记；灰色离线不等于删除。等待和处理中应描述等待对象，取消保持可用。
- 全局问题横幅持续存在直到真实解决；轻量成功反馈使用 aria-live／Qt 可访问公告，不抢焦点。不能用短暂 toast 作为唯一失败说明。
- 弹窗遵守当前平台的确认／取消排序，不用模拟 macOS 红黄绿替换系统窗口。原型圆点仅为窗口示意；正式界面保留平台标题栏。
- 日志／指纹可选择复制，指纹长串换行但不省略安全核对正文；设备长名称单行省略时提供完整可访问名称和详情。

## 键盘与辅助技术

所有功能能通过 Tab／Shift+Tab 到达，焦点环3逻辑像素基准，活动弹窗限制焦点且可 Escape 关闭；有草稿则先确认。Enter 不直接触发危险清除；组合键录制时不误触全局快捷键。拖拽有列表／坐标／键盘替代；选中和状态变化读屏可读。装饰图标不进入读屏，按钮名称不使用不明确的“点击这里”。原型采用 HTML 语义供评审，正式 Qt 需实现 accessibleName、description、role 与焦点顺序并用系统读屏验证。

减少动态效果时取消非必要过渡；加载状态不依赖快速动画。系统颜色／文字缩放切换无需重启页面才可读。长中文、英文、双向文本、超长主机名、200%缩放、键盘布局变化进入实际验收。

## 文案词表

| 情况 | 建议表达 | 避免表达 |
|---|---|---|
| 保存完成 | 已保存，尚未应用。当前共享使用原配置。 | 保存成功，已连接 |
| 应用完成 | 配置已应用，正在等待连接。 | 所有电脑已恢复 |
| 连接完成未测试 | 已连接 · 输入尚未验证 | 设置全部完成 |
| 身份变化 | 此电脑身份已变化，请重新核对完整指纹。 | 自动修复证书 |
| 服务停止失败 | 无法确认后台服务已停止。界面保持打开。 | 已退出，共享已停止 |
| 未知能力 | 当前环境尚未检测到支持。查看详情。 | 平台一定支持 |
| 重试 | 重试连接；保留现有安全要求。 | 自动关闭加密再试 |
| 清理 | 清除当前应用配置目录内的… | 恢复一下／一键修复 |

错误至少包含发生对象、失败步骤、当前保留状态和下一步；错误码折叠到详情，支持复制给开发，不暴露敏感数据。日期时间本地化，容量／间隔统一单位。显示名称、连接标识、服务端等工程词不混用。
