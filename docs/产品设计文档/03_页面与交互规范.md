# 03 页面与交互规范

版本 v0.9 · 待整体确认。与第 04 章状态契约共同使用；原型简化处以本规范及技术核验后的既有语义为准。

## 通用页面约定

顶层展示本机角色、共享状态和重要问题；页面标题说明对象，局部说明指出作用范围。设置按作用域分组，每组只有必要动作。保存失败保留输入、原配置与错误；只读时允许查看、搜索、预览导出，写入、应用、清除、证书重建禁用并说明原因。错误不能仅用红色表示。

返回导航保留页面草稿，不自动提交；弹窗取消不提交；危险操作说明对象、连接中断、文件范围与不可逆影响。加载、空态、失败、成功均需设计。批量变更不得静默提交部分对象。对话框初始焦点落标题／首个非危险操作，关闭后恢复触发控件。

## S01 首次设置与添加电脑

| 步骤 | 字段与操作 | 条件／异常 |
|---|---|---|
| 使用方式 | 两张选择项：键鼠在本机／另一台电脑 | 日常角色变更必须说明中断并应用；不由导航隐式切换 |
| 权限 | 所需能力、检测结果、系统授权入口、重新检测、稍后 | 拒绝不退出应用；未授权不能显示可控制 |
| 等待连接 | 本机标识、可用地址与端口、操作指引、等待状态 | 来源端等待接收端发起；可预先配置离线设备 |
| 发现来源 | 名称、地址、系统（若可信来源可得）、刷新、手动 | 名称可伪造；不作为身份依据；地址变更不自动换信任 |
| 手动地址 | 主机名／IPv4／IPv6、端口、候选列表 | 用核心解析器；手动连接端口 1–65535；IPv6 不用简单冒号切分；拒绝带协议 URL 的误输入并给示例 |
| 核对身份 | 完整摘要、同摘要图案、设备标识、明确确认 | 新／已有／变化分别表达；拒绝保留旧记录，不覆盖不同指纹 |
| 双方确认 | 本机已确认、对方等待／拒绝／超时 | 允许取消、返回检查；不自动同意 |
| 建立连接 | 当前步骤、地址、实际结果、重试 | 配置接受／握手成功／输入可用分开；失败保留旧来源 |
| 排列 | 四方向快捷位置、“完整排列”入口 | 四方向不是全图限制；新位置有冲突时提示或找空位 |
| 输入验证 | 移动与输入指引、证据状态、重试、稍后 | 跳过不写已验证；没有可靠引擎事件时采用明确人工确认且标明证据来源 |
| 完成 | 已连接且已验证／已连接待验证，回设备 | 下一步不再重复要求初次选择 |

表单内容在失败与返回时保留。超时仅结束当次请求，保留已建立的其他会话。请求标识必须区分并发旧请求，防止迟到事件完成已取消的流程。

## S02 设备与完整排列

来源端完整画布支持多行多列、空格、离线图块、选择、拖拽、占位交换、缩放、平移、按设备居中和精确坐标。最大范围与现有模型 100×100 对齐，负坐标可作视图表示，序列化须规范化且不改变邻接关系。角落接触不构成边缘相邻；不把未渲染设备删除。

“调整排列”开始局部草稿，“保存排列”验证范围与名称引用后提交持久配置、标记待应用；“取消”还原。离散拓扑给出无边缘通路的设备清单，可返回调整或明确保留（快捷键／复杂路由可能有意使用）。占用位置交换两台电脑而非覆盖。Alt+方向键移动选中项；编辑坐标提供键盘等效操作。窄窗口提供位置列表，不能让画布成为唯一入口。

图块显示名称、系统、是否本机、连接／身份／待验证。移除前列出快捷键、别名和路由引用，要求重新指定或明确同步移除引用；只移除配置不自动撤销信任。预先添加离线电脑与发现分开。接收端显示来源、本机、未知拓扑说明；完整布局由来源管理，依赖真实同步时另行验收。

## S03 设备高级设置

| 分类 | 内容 | 校验／作用域 |
|---|---|---|
| 名称与标识 | 显示名称、连接标识、多个别名，添加／删除 | 全局唯一检查覆盖标识与所有别名；复用现有合法名规则，不照抄原型 ASCII 正则；改标识需同步引用 |
| 修饰键 | Shift、Ctrl、Alt、Meta、Super、AltGr | 每项映射到全部六类或 None；保存全部值，不压缩为两类 |
| 边缘与角落 | 左上、右上、左下、右下独立开关；尺寸 | 0–99 整数；保留未勾选项的尺寸；语义依引擎 |
| 兼容修复 | CapsLock、NumLock、ScrollLock、XTest、弱 X11 焦点 | 锁定键逐项；XTest／焦点只对目标 X11 显示；未知目标保留旧值，不擅自丢弃 |

设备设置只作用于选中设备；来源端及非文件接管状态可写。接收端或外部文件模式可查看并说明管理位置。更改别名时保留其他设备的值；弹窗切换分类保留草稿。

## S04 通用

语言来自实际翻译清单；启动检查更新只检查，下载和安装另行操作。后台图标单色／彩色、启动显示／后台、关闭时退出／隐藏、标题版本号、共享期间防休眠保留。显示类立即自动保存；自启动、防休眠或系统注册若实际失败要说明“偏好已保存，系统尚未启用”。后台入口不可用时启动隐藏与关闭隐藏采用可返回降级。普通偏好与运行参数分类不能仅按视觉控件划分。

## S05 共享与切换

| 项目 | 范围 / 默认 | 规则 |
|---|---|---|
| 剪贴板开关与容量 | 0–10000 MB；默认 3 | 关闭后禁用容量编辑并保留值；0 的实际引擎含义按旧配置保留，文案核验后说明 |
| 切换延迟 | 独立开关；10–10000 ms；步长10；默认250 | 与双触可同时启用 |
| 双触切换 | 独立开关；10–10000 ms；步长10；默认250 | 不改成互斥选项 |
| ScrollLock、默认锁定、相对鼠标 | 保留既有布尔值 | 不以更换文案反转原设置语义；迁移需对比序列化 |
| 保持前台 | Windows 适用 | 其他平台隐藏编辑但保留已有配置 |
| 心跳 | 独立开关；1000–30000 ms；步长1000；默认5000 | 关闭与数值保留分开；不是自动信任／安全绕过 |

来源管理的设置在接收端解释其作用域，不把接收端本地输入设置一并禁用。保存后待应用。

## S06 高级快捷键

列表包含名称、触发组合、动作数与异常；可新增、编辑、删除。录制键盘／鼠标组合支持取消，系统保留组合和与其他规则冲突分别提示。最终冲突与合法按键依据已有解析和系统注册结果，原型示例黑名单不是完整产品规则。

| 动作 | 参数 | 必须保留 |
|---|---|---|
| 按下按键 / 释放按键 / 按下并释放 | 按键或鼠标按钮、按键目标电脑集 | keydown / keyup / keytap；鼠标路由遵循现有引擎，不能随意广播 |
| 切换到指定电脑 | 有效电脑引用 | 名称修改同步引用，删除前处理失效目标 |
| 按方向切换 | 左／右／上／下 | 与排列相邻逻辑一致 |
| 下一台 | 现有顺序语义 | 不默默改成画布排序 |
| 修改光标锁定 | 切换／启用／解除 | 三种都保留 |
| 重启来源端 | 影响说明 | 重启动作单独确认，不在保存或预览时执行 |

每个动作都有按下／释放触发时机；支持添加、删除、上移、下移且至少一个有效动作。UI 保存完整有序列表。复制粘贴、布局／语言变化后的注册失败必须显式标记，不能显示规则已生效。

## S07 接收端输入

动态重试、语言同步、X/Y 滚轮反向与两轴独立倍率；倍率 0.1–10，步长 0.1，默认1。关闭语言同步不删除布局信息；缺失布局给系统安装指引，不伪装同步成功。“恢复本页默认”只填入草稿，保存后待应用。来源端可查看预设但必须标明该角色当前不使用；不为了查看此页而切换角色。

## S08 本机证书与安全

保留 TLS 开关、要求接收端证书、自定义证书路径、2048／4096 新证书长度、查看指纹、选择文件、重新生成。完整 SHA-256 与 17×9 现有指纹图案来自同一摘要。图案为辅助，摘要可选择复制；不得显示私钥。

选择证书后真实读取、校验配对和可用性；错误保留当前身份。保存路径不立即生效。关闭 TLS 需要独立影响确认，保存和生效时分别持续标示未加密兼容状态，不能把身份视为安全验证通过。重新生成前说明中断与对方重验；生成／替换失败保留旧身份；成功激活新身份后停止连接，要求所有对方重验本机，保留本地独立的远端信任。原型“生成”是立即激活示例身份的路径；正式实现须完成安全文件替换和确认事务。

## S09 设备信任

按设备显示指纹、核对时间／证据（若有）、当前连接与曾验证状态。未知、已信任、变化、撤销区分。身份变化阻断自动重连，不接受重试作为信任；重验显示旧／新摘要和确认原因。撤销需确认对象，成功断开指定会话并停止该身份自动重连，保留位置与其他会话。断开失败应显示“信任已撤销，连接终止待确认”，避免谎报立即断开。再信任不自动连接。

## S10 网络

监听接口来自实际系统接口／IP 枚举，自动／所有适用接口为默认选择；接口消失仍显示旧值与说明。现有端口控件最大65535、未显式设置最小值（Qt 默认0）；新建手动连接要求1–65535，导入的0须先核验引擎语义，不可静默缩窄旧配置。候选来源地址保留多项与实际解析语义；清空／排序／去重前核对旧行为。保存说明监听变更可能中断连接，成功应用后显示实际地址，不在诊断里自动改防火墙。

## S11 配置文件与协议

Synergy／Barrier 保留；选择外部文件路径、只读内容预览、验证和来源说明。校验用真正配置解析器，显示行、列（如可得）、原因与恢复入口。文件可读不代表语法有效。仅保存外部模式仍使用旧生效配置；实际应用后图形管理的相应参数只读。退出外部模式需明确图形配置来源，不把旧文件覆盖成画布节选。

导出路径选择、已有文件覆盖确认、取消、权限错误均需实现。完整导出范围包括电脑、别名、全部映射、角落、修复、规则、链接、共享和协议选项；保留超出图形编辑能力的已有内容。原型预览仅演示节选，不能当作完整序列化器。

## S12 维护与自动化

Windows 安装且非便携模式提供后台服务及守护进程提权；权限／服务不可用时显示原因并保留原运行方式。进入／离开命令分别启用并填写正文，执行位置写明“这台电脑”，空命令不保存，保存和预览不执行。配置只读时不得写入。

恢复普通偏好保留电脑、规则、信任、证书、网络和外部文件。清除应用配置须列出活动 profile 的真实文件范围，提供先导出、确认输入与失败恢复；清除可能包含 profile 内日志和身份，外部文件与系统服务不隐式删除。清除后重新进入 S01。原型只清空内存示例，正式清理路径和重启行为另作集成验收。

## S13 诊断与 S14 日志

诊断按权限、网络、身份、会话、输入分层，每项有实际检测结果、时间、未检查／检查中／异常状态、下一步和重试；没有检测能力时显示未知。连接中断原因、建议、详细代码分层，不以日志大段堆叠代替建议。报告导出先预览、默认隐藏名称／地址，保留平台版本、能力状态和非敏感错误；排除私钥、剪贴板、凭据与自动化正文，不自动上传。

日志等级 Fatal、Error、Warning、Info、Debug、Verbose。GUI 调试独立，文件开关／路径／选择位置保留。查找支持匹配计数、前后跳转、当前高亮；无匹配时说明，不改变原日志。独立窗口与嵌回共用日志源；关闭日志不停止共享。日志偏好明确保存后按真实日志管线结果反馈；若当前实现需核心重启，纳入待应用而不声称立即启用。文件写入失败给恢复路径，环形缓冲／保留策略由工程确认，日志高频更新不得抢焦点或无限增长。

## S15 帮助与 S16 系统入口

关于包含真实版本、构建、平台、开源许可、贡献者、复制版本信息、发布说明。更新有检查中／无更新／有更新／失败，用户主动下载；失败不影响连接。原型不检查网络更新。

菜单栏／托盘只保留状态、当前连接、重要问题与打开、暂停／恢复、开始／停止、重连、退出。多个入口必须读同一状态。重连先说明中断；明确退出的服务语义见第06章。系统通知只做跳转，不在通知上直接信任设备。窗口标题、菜单、首页、诊断使用同一状态词表。
