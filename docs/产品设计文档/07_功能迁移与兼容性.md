## 迁移原则

首次打开新版读取原配置并构建新视图，**不因浏览页面就重写配置**。迁移前保留可恢复备份，明确格式／版本；路径、服务模式和便携模式分别解析。新 UI 无法表达的旧字段原样保留，提供外部文件或高级入口，不把其写成默认值。不能把100×100、多别名、完整映射和多动作简化成早期草图的四方向或单动作。

名称当前参与 settings 键和链接引用。引入稳定 ID 与友好名称之前，建立旧名→新身份／标识的迁移映射，原子更新别名、链接、规则和设备选项；重复、大小写／Unicode 与转义规则复用现有解析器。指纹到友好设备名称的关联需核验，不根据 mDNS 名称自动合并设备。

原来的 ScrollLock 禁用项与新文案若采用正向开关，需要显式语义转换，测试 true/false 两值。语言同步、动态重试、倍率的作用域保持接收端本机；X11 专用值在不适用平台上保留但不误启用。旧的关闭窗口偏好继续可配置；明确退出的行为修订须在发布说明解释。

## 配置完整性验收

至少构造：多行／多列／空洞／离散图；重命名与多别名；六类映射到None；四角及边界尺寸；全部锁定键／X11修复；全部动作类型、按下／释放、多目标与排序；延迟和双触同时开；心跳与容量极值；两协议与外部文件；本机命令、服务、TLS／证书路径。

旧版读取 → 新版查看不保存 → 比较磁盘；旧版读取 → 新版编辑一个字段 → 导出 → 当前真实解析器读回 → 比较完整语义；新版保存 → 旧引擎启动（支持范围内） → 实际行为。文本格式可能不同，不能只做文本 diff；未知／扩展字段必须有明确保留策略。原型导出的链路节选禁止作为生产导出器。

文件模式切换检查“保存”“应用”“重连”三个边界；路径不可读、解析失败、临时写失败、替换失败和回退失败分别注入。证书变更比较真实身份，不能只比较文件名；服务配置不能被桌面偏好错误覆盖。

## 代码核对入口

- [MainWindow](../../src/lib/gui/MainWindow.cpp)：主入口、动态菜单、窗口与日志。
- [SettingsDialog](../../src/lib/gui/dialogs/SettingsDialog.cpp)：保存、网络、服务和平台控制。
- [ServerConfigDialog](../../src/lib/gui/dialogs/ServerConfigDialog.cpp) 与 [ComputerSetupModel](../../src/lib/gui/ComputerSetupModel.h)：完整排列／选项与最大网格。
- [Computer](../../src/lib/gui/config/Computer.cpp) 与 [ServerConfig](../../src/lib/gui/config/ServerConfig.cpp)：设备选项与配置序列化。
- [ActionDialog](../../src/lib/gui/dialogs/ActionDialog.cpp)：动作范围与原校验。
- [CoreProcess](../../src/lib/gui/core/CoreProcess.cpp)：进程／服务停止、配置持久化和应用。
- [FingerprintPreview](../../src/lib/gui/widgets/FingerprintPreview.cpp) 与 [SecureUtils](../../src/lib/net/SecureUtils.cpp)：身份摘要与图案。
- [MdnsBrowser](../../src/lib/net/MdnsBrowser.cpp)：发现来源；[Diagnostic](../../src/lib/gui/Diagnostic.cpp)：清理范围。

以上是当前仓库核对点，重构后更新引用与迁移账本；行号随实现变化不作为协议。
