# M015：Mac 探测消息解码前边界

2026-10-28。对应架构第 12、13、22、26 节；修补 M014 的解码前长度防护缺口。

MacResourceProvider 在使用 QDataStream 解码之前，按 Qt 6.0 固定大端格式检查完整消息：版本、布尔值、摘要长度、显示器数量、每项固定字段与 UUID 字符串长度、尾部边界；拒绝重复系统显示 ID 或 UUID。消息上限 64 KiB、最多 64 个显示器的限制保留。格式不匹配一律返回未知，不得据此确认资源清理。该检查不把 helper 的数据视为远端协议，也不替代已注册可执行文件验证。

Mac 真实输出正常创建并清理通过；另外运行通过可执行文件注册检查的受控夹具，分别发送超大 UTF-16 字符串长度和模拟探测卡住，均未被接受，超时夹具通过原期限检查。非法长度测试覆盖一种故障，不代表已完成完整模糊测试；需要后续增加截断、重复项、所有边界组合及系统级故障注入。公共 Linux 代码未改变，本阶段没有声称 Ubuntu 原生模块测试。

仍待解决注册文件同步读取/哈希和系统进程启动本身的阻塞风险、可执行文件验证到启动之间的替换竞态；不宣称完整超时或供应链认证。生产路径仍未接入本 provider。源码和测试与本备忘录同阶段提交，`git log --follow -- <本文件>` 可定位。
