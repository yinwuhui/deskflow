# M017：既有清理探测回归的等待期限

2026-10-28。对应架构第 22、26、27 节的期限、故障测试与迁移回归要求。

接手基线在 Mac 正常宿主权限下为 114/115，单独重跑 UnknownHostResourceRecovery 仍失败：测试等待约一秒便断言结束，而生产探测允许四秒，失败析构时子进程仍在运行。本阶段使测试以单调时钟等待至多六秒，覆盖生产探测截止及事件交付；没有修改生产超时或放宽清理成功条件。

增加真实子进程故障：先输出合法空拓扑 JSON，再 exec /bin/sleep 10。断言四秒探测截止后仍为 CleanupRequired、账本仍 Pending、没有 Streaming/首帧。直接 exec 避免产生未受监督的 sleep 孙进程。该测试验证既有 MediaSupervisor 探测超时，不替代新 provider 或整个 agent 崩溃恢复认证。

实际验证：Mac 原失败单项通过（4.44 秒），相关回归 115/115（19.67 秒）；Ubuntu 重新构建 DisplayServiceTests 后相关回归 115/115（18.21 秒）。首次沙箱运行有 Qt NEON 探测失败，未计为代码失败或通过；上述 Mac 结果来自正常宿主权限。Ubuntu 同步前检查工作区并确认目标文件 SHA256 与本阶段起点相同，仅同步一个测试文件，保留其余差异。

不涉及原生输出、媒体、真实桌面呈现或跨机验收；未验证 Windows。代码和本备忘录同阶段提交，使用 git log --follow -- 本文件定位。
