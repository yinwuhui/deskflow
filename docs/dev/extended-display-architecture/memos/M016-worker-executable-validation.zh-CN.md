# M016：Worker 可执行文件描述符校验

2026-10-28。对应设计第 4、12、24 和 26 节。本阶段收紧 POSIX 可执行文件校验，**尚未解决从校验到按路径执行之间的替换竞态**。

监督器打开目标时使用 O_NOFOLLOW、O_CLOEXEC 和 O_NONBLOCK；只对同一个打开描述符执行 fstat 与 SHA256，检查普通文件、所有者、权限、大小，以及校验前后的设备号、inode、模式、所有者、大小和时间。校验结束再使用 lstat 确认路径仍指向相同对象。非阻塞打开避免路径被替换为 FIFO 时等待写入者。Windows 校验路径没有本阶段改动，未在 Windows 编译/实测。

Mac 和 Ubuntu 各执行 6/6 监督器回归通过，包含真实子进程和新增的组可写文件、符号链接拒绝检查。Mac 10.68 秒，Ubuntu 11.75 秒；新增注册负例在两端分别通过。同步前逐字节比较远端工作文件与本阶段前一版本，确认相同后仅同步两个文件，保留其他修改。

这些测试没有模拟并发替换，也不证明 QProcess 按路径启动是原子操作。校验后、exec 前仍存在竞态；文件读取/哈希及启动仍可能阻塞；时间戳比较不能代替内核保证。后续应确定 macOS 和 Linux 各自能可靠执行已验证对象的方案、包签名/目录权限策略及故障注入，不能据此标为供应链或完整期限认证。源码、测试和备忘录同阶段提交。
