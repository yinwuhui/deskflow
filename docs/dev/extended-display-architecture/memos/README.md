## 后续每份备忘录的必填内容

1. 模块目标及不在本次范围的事项。
2. 对应设计章节、代码路径、接口/持久化/协议变化。
3. 关键决策和安全/资源不变量。
4. 测试命令、实际环境、结果及故障覆盖。
5. 对既有功能的影响、迁移与回滚边界。
6. 未完成接入、已知限制、平台未验证项。
7. 审查重点与提交定位方式。
