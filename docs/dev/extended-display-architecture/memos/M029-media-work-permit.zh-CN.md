# M029：本地媒体工作许可原语

## 边界与设计对应

对应架构的会话/计划作用域、授权撤销及媒体入口约束。可信本地 owner 在完成授权和输入屏障后签发进程内 `MediaWorkPermit`。本模块只验证结构、固定上下文、有效期与不可逆撤销；不验证设备身份，不替代授权服务，也不从远端 JSON 产生许可。

## 实现与不变量

- 上下文包含完整 WorkerBinding、WorkerPrepare、本地地址、媒体源资源及拓扑代次；匹配比较全部字段。
- 签发拒绝非法绑定、过期准备、错误后端、通配/多播地址、未明确允许的回环及发送源不一致。
- 采集准入进一步核对 owner/session/epoch/plan/userSession、原生来源、稳定身份、拓扑摘要/代次及当前 CPU 采集最低预算；接收方向不能取得采集准入。
- 有效期采用 steady clock，右端点排除。共享原子撤销不可恢复；对象不可复制，不序列化。
- 提取 `validWorkerBinding` 复用原 IPC 构造函数的结构约束；结构检查不等同 IPC 握手认证。
- 本对象不持有帧，不改变已借出帧的租约和回收责任。

## 测试与限制

新增 MediaWorkPermit 行为测试覆盖上下文十二类变更、时间端点、错误签发、源拓扑及方向隔离、四线程反复撤销。Mac/Ubuntu 各 23 项相关协议测试及 137 项完整相关回归通过。实际运行结果见同阶段 M029-test-results.json。

本阶段尚未接入 NativeWebRtcEngine、MacCaptureSource、生产 owner 或隔离 Worker。因此当前媒体样机仍不具备本许可提供的入口拒绝行为，不能宣称已验证实际撤销停止、进程排空、双机或产品授权。未执行新的原生媒体/真实桌面测试；此前模块证据不代替本阶段接入验证。Windows 未编译认证。
